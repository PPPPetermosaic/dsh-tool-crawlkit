# crawlkit · 爬取工具箱

给 [DeepSeek Harness](https://www.deepseek.com)（DSH）用的网页数据工具箱：
让 agent 按站点生成**适配器**，把网页抽成结构化数据，存成可反复取用的数据集。

包名 `dsh-tool-crawlkit` · 插件标识 `crawlkit` · 零第三方依赖

---

## 它是什么

DSH 自带的能力能取回一个页面的纯文本，但拿到的是**一大段看不出结构的文字**：
哪些是标题、哪些是列表、列表有多少条，都得自己再猜。列表页有 50 条也只能一条条读，
而抓回的 HTML 动辄几万字，塞不进上下文。

crawlkit 补上这一段：

```
看清结构  →  按站点生成适配器  →  抽成结构化数据  →  存成可检索的数据集
```

**给谁用**：需要把某个网站的数据变成能反复查询的结构化数据的人。
不写代码也能用——适配器是**纯数据规则**，由 agent 按需生成。

---

## 核心特性

**六个工具**

| 工具 | 做什么 |
|---|---|
| `crawlkit_selfcheck` | 自检运行环境：抓取能力、数据目录是否可写、数据实际落在哪 |
| `crawlkit_read` | 读一页 → 结构摘要（含**可直接用的候选选择器**） |
| `crawlkit_probe` | 探测数据在哪：空壳页判断、内嵌 JSON、接口线索、数据路径 |
| `crawlkit_adapter` | 适配器管理：`list` `template` `get` `save` `test` `delete` |
| `crawlkit_run` | 按适配器抓取，可翻页、去重、续抓、存数据集 |
| `crawlkit_dataset` | 数据集：`list` `view` `search` `delete` |

**适配器：纯数据，两条通道**

- **HTML 通道**：CSS 选择器定位条目与字段
- **JSON 通道**：路径取值（`data.list`、`owner.name`、`data.list[*]`）
- 一条规则可以按 `{keyword}` 这类**占位符参数化**，同一个适配器服务任意查询词

**能力**

- 翻页（页码 / offset / 游标 / 下一页链接）
- 去重（同批内 + 跨批次）
- **续抓**：记住上次抓到哪，下次接着抓，不重复也不断档
- **离线调规则**：把响应存成快照，之后不打网络反复试
- 长字段截断 + 提示注入清洗（只作用于送进模型的内容，**落盘数据保持原文**）
- 失败分类（`needs-browser` / `api-blocked` / `credential` / `blocked` / `empty` …），
  同类失败到阈值后明确标记"不要再试"

## 快速开始

### 一、安装

```
1. 先把包检查一遍（不需要 DSH 在跑、不联网、不写任何文件）
   node check.js          →  应显示「全部通过（10 项）」

2. DSH 侧边栏 →「插件」→ 添加插件 → 指向本目录的绝对路径

3. 重启 DSH
```

### 二、在新对话里调用

**装好之后每个新对话都自带这些工具，不需要"启动"或"加载"。**
但新对话**不认识你的适配器和数据集**，所以开头先让它自己看：

```
用 crawlkit_selfcheck 看下环境          ← 确认装好了、数据落在哪
用 crawlkit_adapter 列出所有适配器        ← 已有哪些规则
用 crawlkit_dataset 列出所有数据集        ← 已抓到哪些数据
```

然后按需要往下走，三种说法都行：

```
① 说需求（让它自己发现该用哪个适配器）
   我想抓某个站上关于「某个话题」的内容

② 点名工具（最可靠：工具名就是明确指令）
   用 crawlkit_run 抓 <适配器id>，params={"keyword":"示例关键词"}，limit=50

③ 新站点第一次（全流程托管）
   帮我看看这个站的数据：先探测、建适配器、抓 200 条存起来。地址是 <URL>
```

> 装机时还没有任何适配器，所以 ② 里的 `<适配器id>` 需要先用 ③ 的方式生成一个
> （或从别人那里拿一份规则）。适配器是纯数据，可以直接贴给你。

> ⚠️ **数据目录跟着「对话的工作目录」走。**
> 在 `D:\a` 开的对话看不到在 `D:\b` 抓的数据。
> 想让所有对话共用一份数据，用配置里的 `dataRoot` 写**绝对路径** —— 见 [docs/使用指南.md](docs/使用指南.md)。
